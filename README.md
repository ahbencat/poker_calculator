# 德州扑克在线胜率计算器

网页版德州扑克（Texas Hold'em）胜率计算器：为 2–10 位玩家选择手牌与公牌，
实时计算每位玩家的获胜概率。全部计算在浏览器本地完成，服务器仅托管静态文件。

> 核心概率计算算法（模式选择、7 张牌评估器、精确枚举、蒙特卡洛）的
> 详细实现与流程图见 [docs/algorithm.md](docs/algorithm.md)。

## 功能

- **玩家增减**：任意增删玩家后自动重新计算（最少 2 位，最多 10 位）
- **计算门槛**：至少 2 位玩家各 2 张手牌后才开始计算（不论桌人数），只计算手牌齐全的玩家（未齐玩家的已选牌按死牌移出牌堆，不参与计算）
- **精确手牌**：52 张牌选择器，已选的牌全局自动置灰
- **公牌可选**：翻牌 / 转牌 / 河牌任意阶段，未发的牌自动补齐
- **两种计算模式**（自动切换）：
  - 所有玩家手牌已知 → **精确枚举**（含翻牌前，结果精确）
  - 有玩家手牌未知 → **蒙特卡洛模拟**（约 65 万次/秒起，展示置信区间）
- **手机竖屏适配**：单列布局、底部弹层选牌、触控目标 ≥ 44px

## 运行

```bash
# 方式一：静态托管（推荐，手机可通过局域网访问）
python3 server.py            # 默认 0.0.0.0:8000，打印局域网地址
python3 server.py 9000       # 指定端口
python3 server.py 8000 127.0.0.1   # 仅本机可访问

# 方式二：直接双击 index.html（file:// 协议同样可用）
```

无任何构建步骤与第三方依赖（服务器为 Python 标准库）。

## 项目结构

```
index.html              页面骨架（经典 <script> 加载，file:// 兼容）
css/style.css           移动优先样式
js/cards.js             牌编码（rank<<2|suit）、输入校验
js/evaluator.js         7 张牌评估器（掩码 + 3 张 8KB 查表，约 2600 万次/秒）
js/engine.js            胜率引擎（createTask 统一入口：模式选择、精确枚举 / 蒙特卡洛 / 预览切换）
js/app.js               UI 状态机、分片调度（MessageChannel）、底部弹层选择器
server.py               静态托管（标准库；屏蔽点文件；默认对局域网开放）
test/                   Node 测试 + Python 对拍脚本
```

## 技术要点

- **评估器**：4 个"恰好出现 k 次"rank 掩码状态机 + 每花色掩码，3 张 8192 项小表
  （顺子/popcount/top5），单次评估零分配；判定顺序利用"7 张内同花不与四条/葫芦共存"
- **精确枚举**：里程计式组合枚举，状态可暂停恢复；每 2048 局面检查一次时限
- **蒙特卡洛**：部分偏置 Fisher–Yates、mulberry32 可种子化、样本方差置信区间、
  时间预算 650ms / SE<0.15% 提前停
- **UI 不卡顿**：计算以 12ms 分片经 MessageChannel 让出主线程（避开 setTimeout 4ms 钳制）；
  翻牌前精确枚举先出蒙特卡洛预览再无缝替换
- **file:// 兼容**：刻意不使用 ES Modules 与 Worker（file:// 下被浏览器同源策略拦截）
